# Projeto do Sistema Ifood

Este é um projeto de um sistema ifood, desenvolvido em Python, que permite a interação entre administradores, clientes, entregadores e restaurantes.

## Requisitos

Certifique-se de ter os seguintes requisitos instalados:

- Python (versão 3.6 ou superior)
- Bibliotecas Python listadas em `requirements.txt`

## Instalação

Para instalar as dependências do projeto, execute o seguinte comando:

```Shell
make install
```

Isso irá instalar as bibliotecas necessárias listadas no arquivo `requirements.txt`.

## Execução

Para executar o sistema, utilize o comando:

```Shell
make run
```

Isso iniciará a interface do sistema de pedidos online, abrindo as páginas do administrador, cliente, entregador e restaurante em guias separadas.

Certifique-se de que os arquivos `administrador.ipynb`, `cliente.ipynb`, `entregador.ipynb` e `restaurante.ipynb` estejam presentes no diretório atual.
